# Intelligent Classroom Monitoring Portfolio

## Goal
Build a polished, responsive single-page FYP showcase that presents the proposed AI classroom monitoring system honestly as a project under development.

## Experience
- Create a premium dark visual system using deep navy surfaces, cyan/blue accents, restrained glow, glass panels, and crisp professional typography.
- Add a sticky navigation bar with active-section highlighting, smooth scrolling, and a compact mobile menu.
- Use measured scroll reveals, animated architecture connections, hover feedback, and target counters while respecting reduced-motion preferences.

## Page structure
1. Hero with FYP status badge, project title, concise research framing, two navigation actions, and an original classroom computer-vision visualization.
2. Project overview with four capability cards.
3. Problem-to-solution presentation covering the stated classroom challenges without unsupported claims.
4. Six project-objective cards, including explicit accuracy targets and planned real-classroom evaluation.
5. Interactive architecture diagram showing camera input, preprocessing, three parallel AI branches, analytics, storage, and instructor dashboard outputs.
6. Three major AI-module panels for face recognition, engagement analysis, and anomaly detection.
7. Clearly labeled “Prototype Dashboard” populated only with “Demo Data.”
8. Categorized technology stack using only the technologies in the proposal.
9. Animated performance cards labeled “Target,” never as achieved results.
10. Included scope versus excluded/future work.
11. Eight-month development timeline.
12. Data and methodology section written as a collection/training plan, not completed work.
13. Privacy and risk management section.
14. Research foundation cards and clearly labeled expected outcomes.
15. Closing call-to-action and concise footer navigation.

## Technical details
- Keep all content on the existing `/` page and use semantic section anchors, as explicitly requested.
- Define the complete color, typography, shadow, and motion system in the global Tailwind v4 stylesheet using semantic tokens.
- Build reusable React components for navigation, section headings, capability cards, architecture nodes, dashboard metrics, stack groups, and timeline entries.
- Use lightweight CSS and IntersectionObserver-based effects rather than adding heavy dependencies.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Verify the page at desktop and mobile widths, including menu behavior, anchor navigation, layout stability, and visible status labels.
